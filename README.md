# Mechatronics Drone Foundation

## Project Overview
This is an independent engineering learning project focused on designing, simulating, building, and testing a modular quadcopter.

The purpose is to develop practical skills in mechanical design, electronics, programming, flight dynamics, and systems integration.

## Project Objectives
- Understand the fundamental systems of a quadcopter.
- Learn to perform engineering calculations and component selection.
- Develop a drone frame using CAD.
- Understand electrical components, sensors, and flight controllers.
- Learn basic flight simulation and autonomous control using ArduPilot.
- Document design decisions, testing, and improvements.

## Future Development
- Autonomous navigation
- Computer vision and test-target tracking
- Low-light and thermal imaging

## Current Status
Phase 1: Project planning and fundamentals.
